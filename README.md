# 🐑 AgroData Chubut: Monitor Geoespacial Ovino

Tablero interactivo desarrollado en Python y Streamlit para el análisis logístico y territorial de la ganadería ovina extensiva (razas Merino y Corriedale) en la Provincia del Chubut.

## 🎯 Objetivo Institucional
Proveer a técnicos territoriales, veterinarios y analistas de políticas públicas de una herramienta de diagnóstico visual que permita:
- Auditar la distribución de la carga animal por Unidad Productiva (UP).
- Planificar la logística de esquila (Plan PROLANA).
- Mitigar emergencias agropecuarias cruzando densidad poblacional ovina con variables climáticas (nevadas intensas, sequías).

## 🛠️ Stack Tecnológico
- **Python 3.x**
- **Streamlit:** Framework ágil para interfaces de datos.
- **Pandas:** Ingesta y limpieza de datos (RENSPA unificado).
- **Plotly:** Renderizado de cartografía base y métricas departamentales.

## 🚀 Despliegue Local
Para correr el proyecto en tu entorno local:

1. Clonar el repositorio:
   `git clone https://github.com/TU_USUARIO/agrodata-chubut.git`
2. Instalar dependencias:
   `pip install -r requirements.txt`
3. Ejecutar el servidor web:
   `streamlit run app_chubut.py`
